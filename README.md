# Employee Management System
A Java-based Employee Management System connected 
to MYSQL that allows user to manage employee records 
through a simple console application.

# Features
-Add Employee
-View All Employees
-Search Employee by ID
-Update Employee
-Delete Employee
-Input validation
-Delete confirmtion
-Update confirmation
-MySQL database integration

# Technologies Used
-Java
-MySQL
-JDBC
-Git
-GitHub
-Visual Studio Code

# Database
The application uses MySQK+L to store employee information.

Employee fields include:
*Employee ID
*Name
*Email
*Phone
*Department
*Salary

# How To Run
1.Install java
2.Install MYSQl
3.Create the requirwd employee database and table.
4.Add the MySQL connector/J library.
5.Update the database connction details in DBConnection.java.
6.Run Main.java.
